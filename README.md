# StreamFan

YouTube · 치지직 · SOOP · Twitch · TikTok에 같은 화면을 **동시에** 보내는 무료 방송 프로그램이에요.

**👉 [다운로드 및 소개 페이지](https://abbis5556.github.io/streamfan/)**

- **Windows**: [StreamFan-Setup.exe 바로 받기](https://github.com/abbis5556/streamfan/releases/latest/download/StreamFan-Setup.exe) (Windows 10/11 64비트)
- 모든 버전: [Releases](https://github.com/abbis5556/streamfan/releases)

## 주요 기능

- 여러 플랫폼 동시 송출, YouTube 로그인으로 스트림 키 자동 입력
- 얼굴 보정 (뽀샤시 · 갸름하게 · 화장), 크로마키 + 배경 사진
- 투네이션 · 위플랩 후원 알림 웹 오버레이
- 화면 · 웹캠 · 텍스트 · 이미지 배치, 오디오 믹서, 녹화

## 설치

1. `StreamFan-Setup.exe`를 받아 실행해요.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 눌러요 (코드 서명이 없는 개인 개발 프로그램이라 뜨는 경고예요).
3. 처음 방송 전에 앱의 **ffmpeg 설치** 버튼을 한 번 눌러 주세요.
