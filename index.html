● StreamFan

한 번 켜면,
모든 플랫폼에 동시에 방송.

YouTube · 치지직 · SOOP · Twitch · TikTok에 같은 화면을 한꺼번에 보내는 무료 방송 프로그램이에요. 광고도, 회원가입도 없어요.

Windows용 무료 다운로드 모든 버전

Windows 10/11 (64비트) · 약 30MB · Microsoft Edge 또는 Chrome 필요

주요 기능

📡 동시 송출

여러 방송 플랫폼에 같은 화면을 동시에 보내요. YouTube는 로그인만 하면 스트림 키가 자동으로 들어가요.

✨ 얼굴 보정

뽀샤시·갸름하게·입술/볼터치 화장까지. 보정 전후를 버튼 하나로 비교해요.

🟩 크로마키

그린/블루 스크린을 지우고 원하는 배경 사진을 넣어요.

🌐 웹 오버레이

투네이션·위플랩 후원 알림 주소를 넣으면 방송 화면에 투명하게 띄워요.

🖥 화면·웹캠·텍스트

화면 공유, 웹캠, 글자, 이미지를 자유롭게 배치하고 오디오 믹서로 소리를 맞춰요.

⏺ 녹화

방송하면서 동시에 내 PC에 녹화 파일로 저장해요.

설치 방법

  1. 위의 무료 다운로드를 눌러 StreamFan-Setup.exe를 받아요.
  2. 실행하면 "Windows의 PC 보호" 창이 뜰 수 있어요. 개인 개발자 프로그램이라 코드 서명이 없어서 그래요. 추가 정보 → 실행을 누르면 돼요.
  3. 설치가 끝나면 StreamFan이 열려요. 처음 방송 전에 앱의 "ffmpeg 설치" 버튼을 한 번 눌러 주세요 (1~3분).

관리자 권한 없이 내 사용자 폴더에 설치돼요. 지우려면 설정 → 앱 → StreamFan → 제거.
